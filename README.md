# 🪚 هاني لخدمات تفصيل دواليب وغرف الملابس بالرياض

![Project Banner](https://i.ibb.co/5hD1dtt0/IMG.jpg)

موقع ويب تعريفي احترافي لتقديم خدمات النجارة وتفصيل الخزائن، غرف النوم، وغرف الأطفال في مدينة الرياض. تم تصميم الموقع ليكون واجهة رقمية حديثة تسهل على العملاء استعراض الخدمات، رؤية معرض الأعمال، وطلب التسعيرات مباشرة عبر الواتساب.

## ✨ المميزات (Features)

* 🎨 **تصميم عصري ومتجاوب (Responsive):** تصميم يتكيف بسلاسة مع جميع الشاشات (هواتف، أجهزة لوحية، شاشات مكتبية).
* 🌙 **الوضع الليلي والنهاري (Dark/Light Mode):** مدمج بالكامل لتوفير تجربة مستخدم مريحة للعين مع زر تبديل سلس.
* 📱 **شريط تنقل عائم للجوال (Mobile Nav Pill):** واجهة مستخدم مخصصة للهواتف الذكية تضمن وصولاً سريعاً للخدمات وأزرار الاتصال.
* 🖼️ **معرض أعمال تفاعلي (Auto-scroll Gallery):** شريط تمرير سلس لعرض صور الأعمال السابقة.
* 💬 **ربط ذكي بالواتساب (WhatsApp Integration):** نماذج اتصال تحول تفاصيل الطلب (الاسم، نوع الخدمة، التفاصيل) برمجياً إلى رسالة واتساب جاهزة للإرسال.
* 🚀 **مهيأ لمحركات البحث (SEO Optimized):** يتضمن جميع وسوم الميتا (Meta Tags) و (Open Graph) لضمان ظهور ممتاز في بحث جوجل وعند مشاركة الرابط على منصات التواصل الاجتماعي.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **HTML5:** لبناء الهيكل الأساسي للصفحة.
* **Tailwind CSS (CDN):** لتنسيق الموقع بالكامل وبناء واجهة المستخدم بسرعة واحترافية.
* **Vanilla JavaScript:** للتحكم في المنطق البرمجي (الوضع الليلي، التمرير التلقائي للمعرض، ومعالجة نموذج الواتساب).
* **Google Fonts:** استخدام خط "Cairo" لدعم الطباعة العربية بشكل أنيق.
